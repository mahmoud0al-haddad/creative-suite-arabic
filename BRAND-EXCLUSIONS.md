# Artwork exclusions

This is an independently maintained Arabic edition. Original code licenses, authors and brand license terms are retained. Protected upstream graphical marks are excluded; licensed application animal icons and independent geometric replacements are retained. Detailed source hashes and reasons are recorded in source-manifest.json.

NASM binary object files are omitted where identified; install NASM for the documented public Windows build. Text Wavefront mesh inputs remain. Post-export include-resource, license and build gate audits are required before publication.
