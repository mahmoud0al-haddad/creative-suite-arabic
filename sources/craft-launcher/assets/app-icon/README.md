# Neutral geometric suite icons

This independent edition uses original geometric grid artwork (square app icons and a separate wide header SVG), licensed MIT OR Apache-2.0. The unchanged upstream ArtCraft mark and its derived graphics have been excluded.

`packaging/icons.sh` regenerates the geometric PNG/ICO/ICNS outputs from the editable square `assets/app-icon/artcraft-launcher.svg`. Existing lowercase machine filenames and application IDs identify program resources, and do not imply an official ArtCraft build.

The original trademark notice in `LICENSE.txt` is retained for historical attribution to excluded upstream art only; `docs/brand/LICENSE-brand.txt` is unchanged. The neutral original artwork is covered by the project MIT and Apache-2.0 notices.
